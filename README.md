# NurpurVasi Digital Craft

Create a world-class premium business website named "NurpurVasi Digitals".

IMPORTANT:

This is not a news website. It is a premium digital agency and portfolio website for Gaurav Bharti.

The design must look comparable to modern international agencies like Apple, Stripe, Framer, Vercel and Awwwards-winning websites.

GENERAL DESIGN RULES

• Ultra premium UI

• Mobile-first

• Fully responsive

• Extremely smooth scrolling

• Soft page transitions

• Premium micro interactions

• Glassmorphism where appropriate

• Rounded corners

• Luxury spacing

• Clean layout

• No clutter

• Fast loading

• SEO-ready

• Accessibility friendly

COLOR PALETTE

Primary:

Deep Navy

Royal Blue

Soft Cyan

Accent:

Purple

Background:

White

Very Light Grey

Do NOT use harsh bright colors.

The colors should be elegant and comfortable for long viewing.

TYPOGRAPHY

Use premium modern typography similar to Apple and Framer.

Large bold hero heading.

Elegant body font.

WEBSITE STRUCTURE

Create these pages:

Home

Services

Portfolio

About

Contact

Do NOT create News.

Do NOT create Tourism.

Do NOT create Online Shop.

Do NOT create Payment Gateway.

HOME PAGE

Build a cinematic hero section.

Large heading:

NurpurVasi Digitals

Subheading:

Premium Website Design • Development • SEO • Digital Solutions

Create two beautiful buttons:

View Portfolio

Get Free Consultation

Add subtle animated background.

Smooth entrance animations.

Floating premium cards.

Animated scroll indicator.

SERVICES PREVIEW

Premium cards with icons.

PORTFOLIO PREVIEW

Modern project cards.

ABOUT PREVIEW

Professional introduction section for

Gaurav Bharti

(No "Dr." anywhere.)

CONTACT CTA

Beautiful modern contact section.

FOOTER

Minimal premium footer.

ADMIN CMS

Create a powerful editable CMS.

Everything must be editable without coding:

Logo

Favicon

Hero Banner

Hero Images

Hero Videos

Services

Portfolio

Gallery

Contact Details

Social Links

Theme Colors

SEO

Meta Tags

Analytics Code

Google Search Console Verification

Animations

Footer

COMPONENT ARCHITECTURE

Build everything as reusable components.

Future pages must easily reuse existing design.

ANIMATIONS

Use premium smooth animations only.

No excessive motion.

Use elegant fade, slide and hover animations.

PERFORMANCE

Optimise images.

Lazy loading.

Fast loading.

Excellent Core Web Vitals.

This prompt establishes the complete design system and architecture for all future development. Keep the structure scalable and easy to extend later without redesign.
